# RSS アプリ要件定義

## 目的

本システムは、RSS / Atom フィードの購読、記事履歴の閲覧、Webhook 通知を行う専用アプリである。ブックマーク、フォルダ、タグ、カスタムニューススクレイピング、ブラウザ拡張は提供しない。

## RSS フィード管理

1. 利用者は URL、タイトル、任意の説明を指定して RSS / Atom フィードを登録できる。
2. URL は HTTP(S) かつ取得・解析可能な RSS / Atom フィードでなければならない。
3. フィード URL は重複登録できない。
4. 利用者はフィードの一覧、詳細、記事履歴を閲覧し、更新・削除できる。
5. 記事履歴はタイトル検索、公開日範囲、ページングに対応する。

## 実行と通知

1. 利用者はフィードを手動実行できる。
2. 定期実行を有効にすると、batch が設定された cron スケジュールでフィードを巡回する。
3. 未通知記事だけを Webhook へ送り、1件以上の送信成功後に記事履歴へ記録する。
4. フィードごとに通知先を選択でき、未選択時は有効な全 Webhook を対象にする。
5. Discord、Slack、Microsoft Teams の Webhook を複数登録・疎通確認・有効化・削除できる。
6. 通知に記事概要を含めるかを全体設定で切り替えられる。

## UI

1. `/` はリダイレクトせずRSS専用ホームを表示する。
2. ナビゲーションは All feeds、登録済みフィード、Preferences だけを表示する。
3. `/` でフィード CRUD と手動取得を操作できる。
4. `/feeds/{id}` でフィード情報と保存済み記事を閲覧・検索できる。
5. `/settings` は General、Automation、Webhooks、LLM のカテゴリタブで設定を切り替える。
6. Automation タブで定期実行とRSS Webhook通知の有効・無効を管理できる。
7. General、Webhooks、LLM タブでテーマ、通知先、LLM接続をそれぞれ管理できる。
8. 旧 `/feeds`、`/rss`、`/rss/{id}` ルートは提供しない。
9. 一覧と設定画面にはキャッチコピー用のヒーロー領域を設けず、主要操作を優先して表示する。

## LLM 接続

1. 利用者は Ollama、vLLM、OpenAI互換の接続先、モデル、任意のAPI keyを設定できる。
2. APIは実際のchat completionが成功した場合だけ設定を保存する。
3. 保存済みAPI keyはレスポンスへ返さず、登録済みかどうかだけを返す。
4. 利用者は保存前の疎通テスト、保存済み設定を使った再テスト、設定削除を行える。
5. LLM接続はRSS以外のコンテンツ取得機能を有効にしない。
