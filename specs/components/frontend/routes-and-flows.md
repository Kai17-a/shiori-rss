# ルートとフロー

## ルート

| Route           | Purpose                                            |
| --------------- | -------------------------------------------------- |
| `/`             | ダッシュボードの概要と最新ブックマーク             |
| `/bookmarks`    | ブックマーク一覧、作成、編集、削除、検索           |
| `/favorites`    | お気に入りブックマークのページング一覧             |
| `/folders`      | フォルダ一覧と作成                                 |
| `/folders/[id]` | フォルダ詳細、配下ブックマークのページング一覧、名前変更、削除 |
| `/tags`         | タグ一覧と作成                                     |
| `/tags/[id]`    | タグ詳細、関連ブックマークのページング一覧、名前変更、削除     |
| `/rss`          | RSS フィードと custom news site の一覧、作成、編集、削除、実行 |
| `/rss/[id]`     | RSS フィード詳細、記事一覧                          |
| `/rss/news/[id]` | custom news site 詳細、scraped article 一覧       |
| `/settings`     | テーマ、webhook、LLM 接続設定                      |

## ユーザーフロー

### ダッシュボード

- 集計値と最新ブックマークのプレビューを表示する
- ブックマーク、フォルダ、タグ、RSS、お気に入りの画面へ遷移できる
- サイドバーの子要素を描画する前にカタログデータを読み込む

### ブックマーク

- URL、タイトル、任意の説明、フォルダ、タグ付きでブックマークを作成する
- モーダルでブックマークを編集する
- 確認後にブックマークを削除する
- タイトルまたは URL で検索する
- フォルダとタグで絞り込む
- 検索や絞り込みによって現在ページが範囲外になった場合は、有効な最終ページへ戻す
- カードまたはリンクから外部 URL を開く
- お気に入り一覧ではスター状態の切り替え、編集、削除とページング閲覧を行える

### フォルダ

- 一覧ページからフォルダを作成する
- モーダルでフォルダ名を編集する
- フォルダ詳細ページを開く
- 確認後にフォルダを削除する
- 選択フォルダに属するブックマークを表示する
- フォルダ詳細から関連ブックマークの編集、削除、お気に入り切り替えができる

### タグ

- 一覧ページからタグを作成する
- モーダルでタグ名を編集する
- タグ詳細ページを開く
- 確認後にタグを削除する
- 選択タグに関連するブックマークを表示する
- タグ詳細から関連ブックマークの編集、削除、お気に入り切り替えができる

### RSS

- RSS 定期実行の有効/無効を切り替える
- RSS 定期実行時の webhook 通知の有効/無効を切り替える
- 一覧ページから RSS フィードを作成する
- モーダルで RSS フィードを編集する
- 作成・編集モーダルで通知先 webhook を任意で選択する（未選択時は全 webhook へ通知）
- RSS フィード詳細ページを開く
- 確認後に RSS フィードを削除する
- RSS フィードを手動実行できる
- RSS フィード一覧はページングし、最後のページを削除した場合は有効なページへ戻る
- RSS フィード詳細では取得済み記事一覧をページング付きで表示し、手動実行後は一覧を再読込する
- LLM 設定済みの場合、RSS を配信しないニュース一覧 URL を登録できる
- custom news site 登録は LLM 解析と実抽出テストを行い、成功時だけモーダルを閉じる
- custom news site 登録・URL 更新の失敗時はモーダルを維持し、API の原因別メッセージと log 照合用 reference ID を error alert に表示する
- custom news site の通知先、定期通知可否、タイトル、説明、URL を編集でき、URL 変更時は再解析する
- custom news site の更新モーダルでは、サイト構造変更時に限り保存時のLLM再解析を任意で選択できる
- custom news site を手動実行し、詳細画面で保存済み記事を検索・ページング表示する

### 設定

- Discord、Slack、Microsoft Teams webhook URL を識別用の名前付きで複数登録する
- RSS と custom news site の全 webhook 通知に記事サマリーを含めるかを切り替える
- 登録済み webhook の一覧を名前と URL で表示する
- 登録済み webhook URL ごとに通知の有効/無効を切り替える
- 入力中または登録済みの webhook の疎通確認を行う
- 確認後に登録済み webhook を削除する
- テーマ切り替えを行える
- Ollama、vLLM、OpenAI 互換 endpoint、model、任意の API key を入力し、接続テストする
- LLM 設定は保存時にも接続確認し、失敗時は入力値を保存しない
- 保存済み LLM API key は再表示せず、登録済み状態と削除操作だけを提供する

## 共通操作

- 主要なナビゲーションはサイドバーを使う
- API 接続失敗時は共通シェルに接続エラーを表示し、ユーザーが再試行できる
- 再接続成功時はフォルダ、タグ、RSS フィード、custom news site のサイドバーカタログを再同期する
- CRUD 操作はカードとモーダルを使う
- フォルダ/タグ/RSS フィード/custom news site 更新後はサイドバー用データを再取得して同期を保つ
