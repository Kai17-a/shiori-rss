# Frontend 仕様

Nuxt 4 SPA は RSS 専用 UI を提供する。

- `/` はサマリーとアクセス時点から直近24時間の通常RSS・カスタムRSS記事を表示する。
- `/feeds` は通常RSSの一覧、作成・更新・削除、手動取得を提供する。手動取得は自動通知設定を上書きし、有効な送信先があれば未通知記事も送る。
- 通常RSSとカスタムRSSは、PNG・JPEG・GIF・WebP（最大1 MB）のアップロードまたは外部画像URLで任意のアイコンを設定でき、一覧カードと詳細画面ヘッダーへ表示する。設定と削除は一覧・詳細の編集モーダルから行える。
- `/feeds/{id}` はフィード詳細と記事履歴を提供し、記事サマリーをプレーンテキスト化して160文字・最大3行で表示する。
- 通常RSSの記事公開日時は、RSS XMLに記載されたUTCオフセットの日時を維持して表示する。
- `/custom-feeds` はLLM解析で作るカスタムRSSの一覧、作成・更新・削除、手動取得を提供する。カスタムRSSは定期巡回の対象外で、取得は画面から手動で行う。
- `/custom-feeds/{id}` はカスタムRSSの詳細と抽出済み記事を提供し、通常RSS詳細と同じリスト型レイアウト、タイトル・公開日の検索、番号付きページネーション、記事サマリーの160文字・最大3行表示を使用する。
- 通常RSSとカスタムRSSの詳細画面は、最大横幅、中央寄せ、ヘッダーカード、検索、記事一覧、公開日時、通知状態、ページネーションを共通コンポーネントで統一して描画する。
- サイドメニューは Home、通常RSS、カスタムRSS、AI analysis data、Preferencesで構成する。通常RSSとカスタムRSSの見出しクリックは折り畳みを切り替えながら各一覧ルートへ移動し、配下から詳細画面へ直接移動できる。AI analysis dataは `/ai-data` へ直接遷移する。
- `/settings` は General、Automation、Webhooks、LLM のカテゴリタブを持ち、テーマ、通常RSSの定期取得、定期実行時の全体通知、Webhook、LLM接続設定を提供する。Automationの設定は手動取得を抑止しない。LLMタブではデフォルトOFFのAI記事解析バッチ、1回の記事数、日次トークン上限、対象期間を設定でき、記事情報の送信とトークン消費に関する注意を表示する。
- `/ai-data` は保存済みAI記事解析データを表示し、記事・配信元・要約の検索、ソース種別と成功状態の絞り込み、ページングを提供する。要約、要点、トピック、キーワード、固有表現、モデル、プロンプト版、トークン数、試行回数、失敗内容を確認でき、LLM設定タブから遷移できる。`Run analysis now` は定期解析がOFFでも同じ制限で解析を実行する。画面はAPIの実行状態を定期取得し、手動または定期解析中はloading表示と `Analysis running` ラベルでボタンを無効化し、画面内にもNuxt UI Alertで実行中であることを表示する。完了後はAlertを自動で消して結果件数を通知し、一覧を再読込する。エラーで停止した場合はAPIの理由をエラーAlertで表示し、次の実行開始時または利用者のDismiss操作で消去する。
- 全画面の右下に `Ask AI` ボタンを固定表示し、クリックすると保存済み記事の横断検索・要約チャット用モーダルを開く。LLMの回答は読み取り専用のNuxt UI EditorでMarkdown表示し、回答が実際に引用した通常RSS・カスタムRSSの記事だけを参照番号付きリンクとして表示する。回答はNDJSONストリームから逐次反映し、Nuxt UIの `ChatMessages` による自動スクロールと `ChatPromptSubmit` のsubmitted・streaming・error状態を使用する。
- 一覧と設定画面は宣伝的なヒーローやキャッチコピーを置かず、操作対象を先頭に表示する。
- サイドバーには Home、RSS feeds、Custom RSS、AI analysis data、Preferencesを表示する。
- 旧 `/rss` と `/rss/{id}` ルートは提供しない。
- API 呼び出しは `useApi` と `/api` reverse proxy を通す。
- 保存、削除、取得、再読込、通知切替などの非同期ボタンは、処理中にNuxt UIの `loading` 状態とLucideの `loader-circle` アイコンを表示して再実行を防ぐ。
